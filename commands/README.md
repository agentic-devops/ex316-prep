# commands/

The point of these files is typing speed and recall, not reading. Cover the
answer, do the task, then check.

| File | Use |
|------|-----|
| `master-commands.md` | Full command reference, grouped by the 16 objectives. Read once, then drill from it. |
| `drill-blanks.md` | Task list with the command redacted. Say or type the full command before looking at the answer. |
| `drill-answers.md` | Answers to `drill-blanks.md`, same numbering. |

## Suggested routine (20-30 min/day)
1. Pick 2-3 objectives from `docs/objectives-map.md` with the lowest confidence score.
2. Work `drill-blanks.md` for those objectives cold, out loud or typed into a scratch file.
3. Check `drill-answers.md`. Anything missed goes in `docs/miss-log.md`.
4. Once a week, do every objective back-to-back, timed, no notes: that is your mock exam warm-up.
5. Update the confidence tracker in `docs/objectives-map.md`.

## Rules
- Never open these files during a timed drill in `questions/`. Only `oc explain`, `--help`, and product docs are allowed there, matching the real exam.
- If a command differs on your cluster version, fix it here — the point is muscle memory for what actually works.
